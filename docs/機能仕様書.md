# ブロック崩しゲーム 機能仕様書

- プロジェクト名: block_break
- 開発技術: Flutter (Dart)
- 対応プラットフォーム: Windows / Web / Android
- 版数: 1.2
- 作成日: 2026-10-17

## 1. 概要

画面上部に配置されたブロックを、下部のパドルでボールを反射して全て破壊するゲーム。
ボールを落下させるとライフを失い、ライフが 0 になるとゲームオーバー。
全ブロックを破壊するとレベルクリアとなり、次のレベルへ進む。
レベルは全 12 段階。パドルは 2 次元（水平・垂直）に移動可能。
レベルごとのハイスコアを記録する。

## 2. 画面構成

### 2.1 タイトル画面（起動直後）

| 要素 | 説明 |
|---|---|
| タイトル | 「ブロック崩し」を画面中央に大きく表示（白、48px 太字） |
| レベル選択 | ラベル「開始: 」+ ドロップダウンで開始レベル（1〜12）を選択。`shared_preferences` で永続化 |
| スタートボタン | 選択したレベルでゲーム画面へ遷移 |

### 2.2 ゲーム画面

| 要素 | 説明 |
|---|---|
| 背景 | 全面を暗色（#101826）で描画 |
| ブロック | 画面上部（y=40 開始）にグリッド状に配置。耐久値により色分け |
| パドル | 画面下部に初期配置。水平・垂直 2D で移動可能（垂直は画面下 1/3 範囲） |
| ボール | 円形。パドルから発射され、壁・パドル・ブロックと衝突する |
| HUD | 左上に SCORE / LEVEL / LIVES / BEST（16px 白文字）。BEST はレベルごとのハイスコア |
| 発射ボタンパネル | `ready` 時に画面中央へ「発射」ボタン + 説明テキストを表示 |
| オーバーレイ | ゲームオーバー時・レベルクリア時に中央パネルとボタンを表示 |

## 3. ゲームプレイ仕様

### 3.1 状態遷移

```
[タイトル画面] --レベル選択+スタート--> [ready] --発射--> [playing] --全ブロック破壊--> [levelClear] --NEXT LEVEL--> [ready]
[ready] --発射--> [playing] --ボール落下(ライフ0)--> [gameOver] --RESTART--> [ready（開始レベル）]
```

- タイトル画面: 起動直後に「ブロック崩し」「開始: レベル選択」「スタート」ボタンを表示
- `ready`: ボールはパドルに付随。画面中央に「発射」ボタンパネルを表示。発射操作で `playing` へ
- `playing`: ボールが移動・衝突する
- `levelClear`: 全ブロック破壊。NEXT LEVEL ボタンで次レベルへ
- `gameOver`: ライフ 0。RESTART ボタンで開始レベルからやり直し

### 3.2 発射

- 発射操作: 画面中央の「発射」ボタン、画面タップ/クリック、または SPACE キー
- 発射角度: 真上（-90°）を基準に ±17.2° の乱数
- 発射速度: `300 + level * 40` px/s（レベル上昇で高速化）

### 3.3 パドル操作

- マウス/タッチ操作: カーソル・指のドラッグ/移動でパドルを 2 次元（水平・垂直）に動かす
- キーボード操作:
  - ←/→ または A/D キーで 600 px/s で水平移動
  - ↑/↓ または W/S キーで 300 px/s で垂直移動
- パドルは画面幅内に水平 clamp、垂直は画面下 1/3 の領域（`y: height - height/3` 〜 `height - 40`）に clamp
- `ready` 状態ではパドルにボールが付随して移動する

### 3.4 ボールの挙動

- 壁（左・右・天井）で反射。下部（画面下縁）を越えると落下
- パドルに当たると反射角が決定される（3.5）
- ブロックに当たると反射し、そのブロックの耐久値を 1 減らす
- 1 フレームに衝突するブロックは最大 1 つ

### 3.5 パドル反射角

パドル中心への相対位置 `rel = (ボールx - パドルx) / (パドル幅/2)`（-1〜1 に clamp）に対し、
反射角 `θ = -90° + rel * 60°` として速度ベクトルを再計算する。

- 中央命中: 真上（θ = -90°）
- 右端命中: 右上 60°（θ = -30°）
- 左端命中: 左上 60°（θ = -150°）

反射後の速度は常にレベル対応の ballSpeed に正規化される。

### 3.6 ブロック

- レベルパターンは 12 種類（全レベル固有）。数字 = 耐久値（1〜3）、`.` = 空きマス
- 耐久値 2・3 のブロックは複数回ヒットが必要。破壊されるまで消えない
- 耐久値による色分け:
  - hits = 1: 青 (#4FC3F7)
  - hits = 2: 橙 (#FFB74D)
  - hits >= 3: 赤 (#EF5350)
- 耐久値 2 以上のブロックは中心に残り耐久値の数値を表示

### 3.7 スコア

| イベント | 加算 |
|---|---|
| ボールがブロックにヒット | +10 |
| ブロック破壊（耐久値 0） | +50 |

### 3.8 難易度（レベルに応じた変化）

| 要素 | レベル 1〜4 | レベル 5〜8 | レベル 9〜12 |
|---|---|---|---|
| ボール速度 | `300 + level*40` px/s（上昇） | 同左 | 同左 |
| パドル幅 | 120 px | 100 px | 80 px |

- パドル幅はレベルが上がるほど 3 段階（120 / 100 / 80 px）に短くなり、反射させにくくなる

### 3.9 ライフ・レベル・ハイスコア

- 初期ライフ: 3
- ボール落下: ライフ -1。ライフが残っていれば `ready` に戻り再発射
- ライフ 0: ゲームオーバー
- レベル数: 全 12 段階。NEXT LEVEL でレベル +1（12 以降は循環）、ボール速度が +40 px/s 上昇
- 開始レベル: タイトル画面で 1〜12 を選択可能。`shared_preferences`（key: `start_level`）に永続化
- ゲームオーバー時の RESTART: 開始レベル（`startLevel`）から再開（スコア・ライフはリセット）
- ハイスコア: レベルごとに記録（key: `hiscore_level_<n>`）。レベルクリアまたはゲームオーバー時にスコアが既存記録より大きければ更新。HUD の BEST に表示

## 4. 入力仕様

| 入力 | 操作 |
|---|---|
| レベル選択（タイトル画面） | 開始レベル（1〜12）をドロップダウンで選択。永続化 |
| スタートボタン | 選択したレベルでゲーム画面へ遷移 |
| 「発射」ボタン | `ready` 時に画面中央に表示。押下でボール発射 |
| マウス/タッチ（ドラッグ・移動） | パドルの 2 次元（水平・垂直）移動 |
| マウス/タッチ タップ | パドル移動 + `ready` 時に発射 |
| ← / A | パドル左移動 |
| → / D | パドル右移動 |
| ↑ / W | パドル上移動（画面下 1/3 範囲内） |
| ↓ / S | パドル下移動（画面下 1/3 範囲内） |
| SPACE | `ready` 時に発射、`gameOver` 時にリスタート |
| ボタン | RESTART / NEXT LEVEL |

## 5. 非機能要件

- 描画は Ticker（vsync）駆動で、フレーム間隔（最大 1/30 s に clamp）で物理更新
- 画面サイズは LayoutBuilder で動的取得し、リサイズに追従
- 衝突判定ロジックは UI 非依存の純粋関数として検証可能
- 開始レベルとハイスコアは `shared_preferences` で永続化（アプリ再起動後も保持）
- アプリ icon は `images/bb_icon.png` を元画像に Windows / Web / Android 各プラットフォームに展開

## 6. 受け入れ条件

1. `flutter analyze` に問題なし
2. `flutter test` 全テスト通過
3. 起動直後にタイトル画面（「ブロック崩し」+ レベル選択 + スタートボタン）が表示されること
4. レベル選択で 1〜12 を設定でき、アプリ再起動後も保持されること
5. レベル選択ラベルと選択肢で「レベル」の文字が重複しないこと
6. パドルがマウス/タッチまたは ↑/↓（W/S）キーで 2 次元に移動し、垂直方向は画面下 1/3 範囲内に限定されること
7. スタートボタン押下でゲーム画面に遷移し、画面中央に「発射」ボタンが表示されること
8. 「発射」ボタン押下（またはタップ/SPACE）でボールが発射され、ブロック・パドル・ボールが描画され、発射・反射・破壊・スコア・レベルクリア・ゲームオーバーが動作すること
9. レベルごとのハイスコアが記録され、HUD の BEST に表示されること
