# ブロック崩しゲーム 詳細設計書

- プロジェクト名: block_break
- 開発技術: Flutter (Dart) / Flutter 3.47.7 stable
- 版数: 1.0
- 作成日: 2026-10-17

## 1. アーキテクチャ

```
lib/
  main.dart                 エントリポイント (BlockBreakApp)
  game/
    entities.dart           モデル（Ball / Paddle / Block）+ パドル反射関数
    collision.dart          衝突判定の純粋関数群
    game_state.dart         ゲーム状態・ループ（GameState: ChangeNotifier）
  ui/
    game_canvas.dart        CustomPainter による描画
    game_screen.dart        入力・HUD・オーバーレイ（GameScreen）
    title_screen.dart       タイトル画面（TitleScreen）
test/
  collision_test.dart       衝突判定ユニットテスト（17件）
  widget_test.dart          Widget テスト（HUD 描画）
```

- 依存方向: `ui → game`。`game` は Flutter UI に非依存（`dart:ui` の几何型のみ使用）で単体テスト可能。
- 状態管理: `GameState` は `ChangeNotifier`。UI は `AnimatedBuilder(animation: _state)` で購読し、`notifyListeners()` で再描画。
- 永続化: 開始レベルは `shared_preferences`（key: `start_level`）に保存し、アプリ再起動後も保持。

## 4. 関数仕様

### 4.1 collision.dart

#### `Offset? circleRectCollision(Offset center, double radius, Rect rect)`
- 機能: 円と矩形の衝突判定。矩形上の最近点（クランプ）を求め、中心との距離が半径以下なら接触点を返す。非接触なら null。
- 算法: `closestX = clamp(center.dx, rect.left, rect.right)`、同様に Y。`dx²+dy² <= r²` で判定。

#### `Offset? wallBounce(Ball ball, Size field)`
- 機能: 左壁 (x-r<=0 かつ vx<0)、右壁 (x+r>=width かつ vx>0)、天井 (y-r<=0 かつ vy<0) で速度成分を反転。下部は反射しない（落下）。反射発生時は新速度を返す。なしなら null。
- 注意: 「壁外へ向かっている」条件付きで反転し、同一フレームの再反射を防ぐ。

#### `bool blockBounce(Ball ball, Block block)`
- 機能: 円-矩形衝突で接触点を取得。矩形中心から接触点へのベクトル (dx, dy) で衝突面を判定する。
  - `|dx|*height > |dy|*width` → 左右面: vx を反転、x を `rect.left - r` または `rect.right + r` に補正（penetration 解消）
  - それ以外 → 上下面: vy を反転、y を `rect.top - r` または `rect.bottom + r` に補正
- 返り値: 衝突時 true（ball の position/velocity を書き換える）。

### 4.2 entities.dart

#### `Offset paddleReflectVelocity(Offset center, Paddle paddle, double speed)`
- `rel = clamp((center.dx - paddle.x) / (width/2), -1, 1)`
- `θ = -π/2 + rel * π/3`
- 返り値: `Offset(speed*cos θ, speed*sin θ)`

### 4.3 game_state.dart

| メソッド | 仕様 |
|---|---|
| `initializeSize(Size s)` | size<=0 は無視。`level = startLevel - 1`、paddle を中央・y=height-60 に配置、`_buildBlocks`、`_resetBall`。notify しない（builder 内で安全に呼ぶため） |
| `setStartLevel(int l)` | `startLevel = l.clamp(1, 12)`、`level = startLevel - 1`、score=0、lives=3、`_buildBlocks`、`_resetBall`、notify |
| `_paddleMinY` / `_paddleMaxY` | ゲッター。`height - height/3` / `height - 40`。パドル y の可動範囲（画面下 1/3） |
| `paddleWidth` | ゲッター。難易度 3 段階: L1-4→120 / L5-8→100 / L9-12→80 px |
| `_makePaddle()` | `paddleWidth` を用いて中央 x・y=height-60 にパドル生成 |
| `setSize(Size s)` | size<=0 は無視。paddle を中央・y=height-60 に配置、`_buildBlocks`、`_resetBall`、notify |
| `_buildBlocks()` | 現レベルパターンからブロック生成。`bw = width/cols`、矩形 `(c*bw+2, 40+r*bh+2, bw-4, bh-4)`。`'.'` はスキップ |
| `_resetBall()` | ボールをパドル上 (paddle.x, paddle.y - r - 2) に、速度 zero、status=ready |
| `launch()` | status==ready のみ。`angle = -π/2 + rng*0.6 - 0.3`、速度 = ballSpeed の方向、status=playing |
| `movePaddleTo(double x, [double? y])` | paddle.x を画面内 clamp。y 指定時は paddle.y を上下可動範囲に clamp。ready 時はボールを付随移動、notify |
| `update(double dt)` | 下記 5. のゲームループ |
| `_movePaddleKeyboard(dt)` | 押下フラグで paddle.x を 600*dt、paddle.y を 300*dt 移動、x は画面幅 / y は上下可動範囲に clamp、ready 時ボール付随 |
| `nextLevel()` | level++、`_buildBlocks`、`_resetBall`、notify |
| `restart()` | score=0、lives=3、level=0、`_buildBlocks`、`_resetBall`、notify |

## 5. ゲームループ（update(dt)）

```
1. _movePaddleKeyboard(dt)            # キー入力反映（status によらず）
2. status != playing なら return
3. ball.position += velocity * dt
4. wallBounce → 速度更新
5. velocity.dy > 0 かつ パドル衝突 → paddleReflectVelocity で速度更新、
   position.y = paddle.y - radius に補正
6. blocks を走査、blockBounce 成功時:
     hits-- / score += 10 / hits<=0 なら alive=false, score += 50 / break
7. ball.position.dy - radius > height → lives--
     lives<=0 → gameOver / else _resetBall()
8. blocks.every(!alive) → levelClear
9. notifyListeners()
```

- 駆動: `GameScreen._tick`（Ticker）。`dt = now - last` を 0〜1/30 s に clamp して `update` を呼ぶ。
- パドル衝突は下降中（dy>0）のみ判定し、パドル内での往復反射を防ぐ。

## 6. UI 設計

### 6.1 game_screen.dart

- `GameScreen` (StatefulWidget) → `_GameScreenState`
  - `initState`: `createTicker(_tick)..start()`。`dispose` で `dispose()`
  - `_tick(Duration)`: 前フレーム時刻との差分 dt を算出、`update(dt)`
  - `_handleKey`: `Focus(onKeyEvent)`。←/A, →/D の KeyDown/Up で押下フラグ、SPACE で launch/restart
  - `build`: `LayoutBuilder` でサイズ取得 → 初回ビルド時に builder 内で `initializeSize(size)` を即座に呼ぶ（notify しないため builder 内で安全。初回描画でブロック・パドル・ボールが描画され黒画面を防ぐ）
    - `Listener`: `onPointerMove` → `movePaddleTo`、`onPointerDown` → `movePaddleTo` + ready 時 `launch`
    - ゲーム要素: `AnimatedBuilder` 内で `Stack` + `Positioned` + `Container` によりブロック・パドル・ボールを描画（標準ウィジェット。CustomPaint/Impeller 描画問題を回避）
    - HUD: `AnimatedBuilder` で SCORE / LEVEL / LIVES / BEST（レベルごとのハイスコア）
    - ハイスコア: `shared_preferences`（key: `hiscore_level_<n>`）。`_onStateChanged` で playing→levelClear/gameOver 遷移時に既存より大きければ更新、`_loadHighScore` で起動時に読込
  - `_overlay`: status に応じ
    - `ready`: 画面中央に発射ボタンパネル（「発射」ボタン + 説明テキスト）
    - `gameOver`: RESTART ボタンの中央パネル
    - `levelClear`: NEXT LEVEL ボタンの中央パネル
    - `playing`: 表示なし
  - `_hudChip`: 16px 白文字・タブ数字表示

### 6.2 game_canvas.dart

- 現在は `blockColor(int hits)` のみを使用（1→#4FC3F7、2→#FFB74D、3以上→#EF5350）。`game_screen.dart` から `import 'game_canvas.dart' show blockColor` で参照
- `GamePainter`（CustomPainter）は Windows + Impeller バックエンドで描画されない問題があり、ゲーム要素の描画には使用していない（参考実装として保持）
- ゲーム要素（ブロック・パドル・ボール）は `game_screen.dart` 内で標準ウィジェット（`Positioned` + `Container`）により描画

### 6.3 title_screen.dart

- `TitleScreen` (StatefulWidget) → `_TitleScreenState`
  - `initState`: `shared_preferences`（key: `start_level`）から開始レベルを読込（既定 1）
  - `Scaffold(backgroundColor: #101826)` 中央に `Column`
  - タイトル「ブロック崩し」（白、48px 太字）
  - レベル選択: ラベル「開始: 」+ `DropdownButton<int>`（1〜12）。変更時 `setState` + `shared_preferences`（key: `start_level`）に保存
  - `FilledButton`「スタート」→ `Navigator.push(MaterialPageRoute(builder: (_) => GameScreen(startLevel: _level)))`

### 6.4 main.dart

- `BlockBreakApp` (StatelessWidget) → `MaterialApp(home: TitleScreen())`
