# アイコン差し替えツール 説明書

`tools/` 配下の Python スクリプトにより、元画像（既定 `images/bb_icon.png`、`-s/--src` で任意のパスを指定可）から
Windows / Web / Android のアプリアイコンをまとめて再生成できるツールです。

## 対象ファイル

| ファイル | 説明 |
|---|---|
| 元画像（既定: `images/bb_icon.png`） | 正方形 PNG（推奨 512×512 以上、RGBA 対応）。`-s/--src` で任意のパスに差し替え可 |

## ツール一覧

| スクリプト | 用途 |
|---|---|
| `tools/make_icons.py` | 元画像から全アイコンを再生成（`-s/--src` で元画像を指定可） |
| `tools/icon_check.py` | 生成済みアイコンと元画像の画素照合レポート出力（`-s/--src` で元画像を指定可） |

## オプション引数

両スクリプトとも、使用する元画像を `-s` / `--src` で指定できます。
未指定の場合は既定の `images/bb_icon.png` が使われます。
相対パスはプロジェクトルート（リポジトリの直下）基準、絶対パスはそのまま使われます。

| オプション | 既定値 | 説明 |
|---|---|---|
| `-s`, `--src` | `images/bb_icon.png` | 参照する元画像のパス |
| `-h`, `--help` | - | ヘルプ表示 |

## 前提

- Python 3.x
- Pillow（PIL）: `pip install pillow`

確認:

```bash
python -c "import PIL; print(PIL.__version__)"
```

## 使い方

### 1. アイコンを再生成する

元画像を準備した後、以下のコマンドを実行します。

```bash
# 既定の images/bb_icon.png を使う
python tools/make_icons.py

# 別の元画像を使う（-s / --src で指定）
python tools/make_icons.py --src images/my_icon.png
python tools/make_icons.py -s C:/icons/logo.png   # 絶対パスも可
```

以下のファイルが再生成されます：

- **Windows**
  - `windows/runner/resources/app_icon.ico`（16/24/32/48/64/128/256px のマルチサイズ ICO）

- **Web**
  - `web/favicon.png`（32px）
  - `web/icons/icon_48.png` 〜 `web/icons/icon_512.png`
  - `web/icons/Icon-192.png` / `Icon-512.png`（PWA: manifest.json 参照）
  - `web/icons/Icon-maskable-192.png` / `Icon-maskable-512.png`（PWA maskable）

- **Android**
  - `android/app/src/main/res/mipmap-mdpi/ic_launcher.png`（48px）
  - `android/app/src/main/res/mipmap-hdpi/ic_launcher.png`（72px）
  - `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png`（96px）
  - `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png`（144px）
  - `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`（192px）

### 2. 照合レポートを出す

生成したアイコンが元画像に基づいているかを確認します。

```bash
# 既定の images/bb_icon.png と照合
python tools/icon_check.py

# 指定した元画像と照合
python tools/icon_check.py --src images/my_icon.png
```

各アイコンの寸法・中央領域の平均色・alpha 値をレポートします。
元画像と平均色の差が 24 以内なら `MATCH`、それ以外は `DIFF` と表示されます。

```
images/bb_icon.png | dim=(128, 128) | avg=(253, 253, 253) | alpha=34
--------------------------------------------------
windows/runner/resources/app_icon.ico | dim=(256, 256) | avg=(253, 253, 253) | alpha=34 | MATCH
web/favicon.png | dim=(32, 32) | avg=(253, 253, 253) | alpha=33 | MATCH
web/icons/icon_192.png | dim=(192, 192) | avg=(253, 253, 253) | alpha=34 | MATCH
web/icons/Icon-192.png | dim=(192, 192) | avg=(253, 253, 253) | alpha=34 | MATCH
web/icons/Icon-512.png | dim=(512, 512) | avg=(253, 253, 253) | alpha=34 | MATCH
android/app/src/main/res/mipmap-mdpi/ic_launcher.png | dim=(48, 48) | avg=(253, 253, 253) | alpha=33 | MATCH
android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png | dim=(192, 192) | avg=(253, 253, 253) | alpha=34 | MATCH
```

レポートは標準出力に加え `tools/icon_report.txt` にも書き出されます。

## 再生成後のビルド

アイコンを差し替えた後は、各プラットフォームで再ビルドが必要です。

```bash
# Windows
flutter build windows --release
# → build\windows\x64\runner\Release\block_break.exe

# Android
flutter build apk --release
# → build\app\outputs\flutter-apk\app-release.apk

# Web
flutter build web
# → build\web\
```

## アイコンが反映されない場合の対処

- **Windows**: タスクバーやファイルエクスプローラーのアイコンが古い場合、
  OS のアイコンキャッシュが原因です。
  ```cmd
  ie4uinit.exe -show
  ```
  を実行するか、PC を再起動してください。
- **Android**: 端末に既存アプリがインストール済みの場合、アイコンがキャッシュされます。
  アンインストール → 再インストール（または APK の `versionCode` を上げて再インストール）で解決します。
- **Web**: ブラウザのキャッシュをクリアしてください（`Ctrl+Shift+R` や開発者ツールの「Cache disabled」）。

## よくある質問

**Q: 元画像の推奨サイズは？**
A: 512×512 以上の正方形 PNG が推奨です。128×128 も動作しますが、
Android `xxxhdpi`（192px）や Web `icon_512` などに拡大縮小されるため、
解像度不足になることがあります。

**Q: 元画像は `images/bb_icon.png` に固定ですか？**
A: いいえ。`-s` / `--src` で任意のパスを指定できます。
相対パスはプロジェクトルート基準、絶対パスも利用可能です。未指定時は既定の `images/bb_icon.png` を使います。

**Q: 透過は使えますか？**
A: はい。RGBA をサポートしています。Windows / Web / Android すべてで
透過 PNG がそのまま使えます。

**Q: 色味が違うように見える**
A: `tools/icon_check.py`（必要なら `--src` を指定して）で平均色を確認してください。
`DIFF` と出た場合、元画像が想定と異なる可能性があります。

## 参考: スクリプトの中身

- `make_icons.py`
  - `argparse` で `-s/--src` を受け取り（既定 `images/bb_icon.png`）
  - `Pillow.Image` で元画像を読み込み
  - `Image.LANCZOS` リサイズして各ターゲットパスに書き出し
  - Windows `.ico` は `append_images` でマルチサイズに埋め込み
- `icon_check.py`
  - `argparse` で `-s/--src` を受け取り（既定 `images/bb_icon.png`）
  - 各アイコンを RGBA に変換し、白背景に alpha 合成
  - 中央 1/2 領域の平均色を計算
  - 元画像との色差（最大 24 以内で MATCH）をレポート
